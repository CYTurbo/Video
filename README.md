# AI-Video-Studio

A free, open-source, AI-operated video editing and motion-graphics workstation:
FFmpeg + Remotion + Blender + Python (librosa, OpenCV, PySceneDetect, faster-whisper), driven by
natural-language instructions through Claude Code or a simple CLI.

- Setup on Windows: `AI-Video-Studio/windows/setup.ps1` (see `AI-Video-Studio/docs/SETUP_REPORT.md`)
- First edit: `AI-Video-Studio/docs/WORKFLOW.md`
- Verified capabilities: `AI-Video-Studio/docs/CAPABILITIES.md`
- Test results: `AI-Video-Studio/docs/TEST_RESULTS.md`
